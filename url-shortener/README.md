# URL Shortener

A production-ready URL Shortener built incrementally using FastAPI.

## Project Goal

Build a scalable URL shortening service while learning modern backend development from first principles.

## MVP-1 Features

- Create a short URL
- Redirect to original URL
- Store URLs in PostgreSQL
- Health Check API

## Planned Features

- Authentication (JWT)
- Analytics
- Custom aliases
- URL expiration
- Redis caching
- Docker
- Kubernetes
- CI/CD
- Monitoring

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
